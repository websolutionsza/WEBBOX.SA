Privacy Policy

How the WEB BOX public website handles your information.

Last updated: 2026. This document describes the public WEB BOX website only. It will be updated when backend features are introduced.

Summary

  • WEB BOX does not require an account.
  • WEB BOX does not collect personal information through accounts, payments, contact forms or analytics by default.
  • The local profile stores your display name, selected preset character and an optional profile image on this device only, using browser storage (localStorage and IndexedDB).
  • Custom profile images never leave your device.
  • WEB BOX does not use cookies, tracking or analytics unless a future update introduces them and updates this policy.
  • Third-party destinations linked from the library have their own privacy policies and practices.

What WEB BOX stores on your device

The WEB BOX local profile uses two browser-storage mechanisms on your device:

  • localStorage — to remember your chosen display name and the identifier of the preset character you have selected. This is plain text and a short identifier; nothing sensitive is stored here.
  • IndexedDB — to store an optional custom profile image you choose from your device. The image stays in your browser's IndexedDB store on this device. It is never uploaded to WEB BOX, to Supabase, or to any public storage bucket.

You can clear this data at any time by using your browser's "Clear browsing data" or "Site settings" features, or by removing the custom image from the Profile page.

What WEB BOX does not do

  • WEB BOX does not create a synchronised online account for you.
  • WEB BOX does not ask for, store, or transmit your name, email, password, phone number or any other personal identifier.
  • WEB BOX does not operate a contact form that sends data to a backend.
  • WEB BOX does not process payments or store billing information.
  • WEB BOX does not use analytics, advertising, or behavioural tracking on the public website in its current state.
  • WEB BOX does not set cookies for tracking, advertising or session management in its current state.

No consent banner — because there is nothing to consent to

Because WEB BOX does not use tracking, analytics, advertising or cookies, there is no consent banner on this website. If a future update introduces any of these mechanisms, this policy will be updated and the appropriate consent interface will be added before those mechanisms become active.

Third-party destinations

Some entries in the WEB BOX library link to third-party games and websites. When you launch a game, you leave the WEB BOX website and arrive at a destination operated by a different party. That destination may have its own privacy policy, terms, cookies, analytics, advertising, account system and data practices. WEB BOX does not control, endorse or take responsibility for the privacy practices of any third-party destination.

External game destinations are opened in a new browser tab using rel="noopener noreferrer" behaviour, which prevents the new page from accessing the WEB BOX window through JavaScript.

External resources loaded by the website

To render correctly, the public website loads the following external resources:

  • Web fonts (Sora and Manrope) from Google Fonts.
  • The WEB BOX logo and favicons from the configured asset locations (currently the supplied GitHub raw URLs; will be served from your own domain in production).
  • The optional startup intro video, if and when supplied.

Each of those external providers may log standard request information (such as IP address) according to their own privacy policies. WEB BOX does not control their logging practices.

Children

WEB BOX is a general-audience gaming library. It is not directed at children under the age required by your jurisdiction, and WEB BOX does not knowingly collect personal information from anyone. If you believe a minor has provided information to WEB BOX in error, please use the channels on the Support page and the data will be removed.

Changes to this policy

When backend features are later introduced — for example Supabase-backed catalogue access, optional accounts, or support for game submissions — this Privacy Policy will be updated to accurately describe the new functionality before that functionality becomes active.

Contact

Questions about this policy can be sent through the official WebSolutionsSA channels listed on the Support page.

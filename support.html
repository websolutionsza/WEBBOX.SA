How we can help with WEB BOX

WEB BOX is a public gaming library. Below are quick answers to common questions and the official WebSolutionsSA channels you can use to reach out.

Quick guidance

  • Finding a game: Use the search field on the homepage and combine it with the category chips to filter the catalogue.
  • Launching a game: Open any game in the library to view its detail page. The launch button is only enabled when a valid destination has been configured. Sample entries currently have no destination set.
  • Your profile: Visit the Profile page to pick a preset character, set a display name and add an optional local image. Your profile is stored on this device only.
  • Reporting a problem: Use one of the official WebSolutionsSA channels below. Please include the page URL and a short description.

No live chat or ticket system. WEB BOX does not currently operate a real-time support channel or a support-ticket backend. Please use the official WebSolutionsSA channels below.

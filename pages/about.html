About WEB BOX SA

A free, independent place to discover and browse a curated browser game library.

What WEB BOX SA is

WEB BOX SA is a free, independent browser game library. Its purpose is to provide a single, well-designed place to browse a curated catalogue of browser-playable games — complete with artwork, metadata and direct launch links where they are configured. The product is built for people who want a cleaner, more focused way to discover games, without the noise of generic storefront interfaces.

The library experience is the homepage itself: a featured selection at the top, a forgiving search field, category filters and a varied grid of catalogue entries. Each entry opens a detail page with the game's artwork, metadata and a launch button — the launch button is only enabled when a valid external destination has been configured and the entry is marked as available.

WEB BOX SA is completely free to use. There is no registration, no subscription and no payment system. The website is hosted on Cloudflare Pages and uses a Supabase backend for the catalogue. No credentials, no uploads and no privileged access ever live in the browser.

What WEB BOX SA is not

  • WEB BOX SA does not claim ownership of any third-party game titles, artwork, trademarks or external destinations.
  • WEB BOX SA is not an account system. The local profile does not create a synchronised online account.
  • WEB BOX SA does not host, sell, redistribute or modify third-party games. It is a discovery layer that links to external destinations when those destinations have been configured.
  • WEB BOX SA does not collect personal information through accounts, payments, contact forms or analytics by default.
  • WEB BOX SA does not guarantee that every entry will remain accessible. Game availability depends on third-party sources.

Third-party content notice

Some entries in the WEB BOX SA library link to third-party websites and games operated by parties unaffiliated with WEB BOX SA. Those destinations — and all content, terms, privacy practices and policies associated with them — belong to their respective owners.

WEB BOX SA does not operate, control, endorse or take responsibility for the content, availability, security or behaviour of any third-party destination. Launching a third-party game opens the destination in a new browser tab using rel="noopener noreferrer" behaviour. Once you leave the WEB BOX SA website, you are subject to the destination's own terms and policies.

Some entries may be marked unavailable, pending review or removed. This typically happens when the destination is no longer reachable, has been taken down following a copyright complaint, or is being verified. Removed entries do not appear in the public library at all.

If you operate a game that is listed in WEB BOX SA and you would like the listing updated, removed or corrected, please use the feedback option on the Support page.

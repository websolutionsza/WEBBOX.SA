About WEB BOX

A convenient place to discover and browse a curated game library.

What WEB BOX is

WEB BOX is a public gaming library and discovery platform. Its purpose is to provide a single, well-designed place to browse a curated catalogue of games — complete with artwork, metadata and direct launch links where they are configured. The product is built for people who want a cleaner, more focused way to discover games, without the noise of generic storefront interfaces.

The library experience is the homepage itself: a featured selection at the top, a forgiving search field, category filters and a varied grid of catalogue entries. Each entry opens a detail page with the game's artwork, metadata and a launch button — the launch button is only enabled when a valid external destination has been configured.

This phase of WEB BOX is a public frontend. The catalogue currently runs against a small, clearly-marked sample dataset. When the backend is ready, that dataset will be replaced by a Supabase-backed catalogue accessed through same-origin Cloudflare Pages Functions. No credentials, no uploads, and no privileged access ever live in the browser.

Who built WEB BOX

WEB BOX is created by Tlhompo Meje, a web developer, under the WebSolutionsSA development brand.

The interface, layout and visual identity of WEB BOX are original work by Tlhompo Meje. The website is not a clone of any existing gaming brand, storefront or console interface.

What WEB BOX is not

  • WEB BOX does not claim ownership of any third-party game titles, artwork, trademarks or external destinations.
  • WEB BOX is not an account system. The local profile does not create a synchronised online account.
  • WEB BOX does not host, sell, redistribute or modify third-party games. It is a discovery layer that links to verified external destinations when those destinations have been configured.
  • WEB BOX does not collect personal information through accounts, payments, contact forms or analytics by default.

Third-party content notice

Some entries in the WEB BOX library may link to third-party websites and games operated by parties other than WEB BOX and WebSolutionsSA. Those destinations — and all content, terms, privacy practices and policies associated with them — belong to their respective owners.

WEB BOX does not operate, control, endorse or take responsibility for the content, availability, security or behaviour of any third-party destination. Launching a third-party game opens the destination in a new browser tab using rel="noopener noreferrer" behaviour. Once you leave the WEB BOX website, you are subject to the destination's own terms and policies.

If you operate a game that is listed in WEB BOX and you would like the listing updated, removed or corrected, please reach out through the official WebSolutionsSA channels on the Support page.

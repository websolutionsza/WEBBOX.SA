How we can help with WEB BOX SA

WEB BOX SA is a free, independent browser game library. Below are quick answers to common questions and a feedback form you can use to report problems or send suggestions.

Quick guidance

  • Finding a game: Use the search field on the homepage and combine it with the category chips to filter the catalogue.
  • Launching a game: Open any game in the library to view its detail page. The launch button is only enabled when a valid destination has been configured and the entry is marked as available.
  • Availability badges: Games may show an Unavailable, Pending review or Removed badge. Removed entries do not appear in the library at all.
  • Your profile: Visit the Profile page to pick a preset character, set a display name and add an optional local image. Your profile is stored on this device only.
  • Reporting a problem: Use the feedback form below. Please include the game title or library reference (the slug shown on each detail page) and a short description of the issue.

No live chat. WEB BOX SA does not operate a real-time support channel. The feedback form below is the primary way to report issues. No name or contact details are required, but that also means we cannot reply to you individually.
